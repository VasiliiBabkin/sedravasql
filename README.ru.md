# SedravaSQL

**Экспериментальная встраиваемая СУБД на Rust и SQLite с приоритетом безопасности изменений.**

[English README](README.md)

> **Состояние: прототип исходного кода.** Реализация и тесты написаны, но сборка Rust и выполнение тестов **пока не подтверждены**. Нет стабильного API, релиза, резервирования и подтверждённых гарантий надёжности. **Не используйте SedravaSQL для хранения важных данных.**

## Зачем нужен проект

Мы исследуем СУБД, которая помогает проверять изменения до выполнения, вести историю операций и применять явные правила безопасности. Проверяемое восстановление после сбоев остаётся будущей задачей.

В рабочей ветке подготовлен исходный код библиотеки и CLI на Rust поверх SQLite. Пока это **только ограниченное хранилище текстовых пар ключ–значение**, а не универсальная SQL-СУБД. Код ещё не прошёл подтверждённую сборку и испытания.

SedravaSQL развивается отдельно от [языка Sedrava](https://github.com/VasiliiBabkin/sedrava), чтобы ею могли пользоваться приложения на разных языках.

## Что уже работает?

Есть исходный код прототипа, но **нет проверенного работоспособного релиза**. Инструкции по сборке и демонстрационные команды опубликованы ниже.

| Направление | Статус |
| --- | --- |
| Цели, архитектура, критерии проверки | Черновая документация готова |
| Ядро и CLI | Исходный код есть; сборка не проверена |
| SQL-интерфейс | Ограниченный SELECT; код не испытан |
| Предпросмотр удаления по префиксу | Прототип в коде; не испытан |
| Журнал управляемых изменений | Прототип в коде; не испытан |
| Проверяемое восстановление | Не реализовано |
| Стабильный API и производственный релиз | Отсутствуют |

## Как попробовать

Только для тестовых данных. Установите Rust 1.89+ и компилятор C, затем выполните `cargo build` и `cargo test`. Полные команды и оговорки — в [документации прототипа](docs/PROTOTYPE.md). Автоматическая сборка, установщик и релиз пока отсутствуют.
