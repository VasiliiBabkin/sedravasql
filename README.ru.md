# SedravaSQL

**Проект СУБД с приоритетом безопасных изменений и проверяемого восстановления.**

[English README](README.md)

> **Состояние: проектирование.** Рабочего движка, исполняемой программы, стабильного API, релизов и проверенных гарантий надёжности пока нет. **Не используйте SedravaSQL для хранения важных данных.**

## Зачем нужен проект

Мы изучаем возможность создания СУБД, которая позволяет проверять опасные изменения до выполнения, объяснять историю операций, применять явные правила безопасности и испытывать восстановление после сбоев.

Предполагаемая первая архитектура — ядро на Rust с SQLite в качестве транзакционного хранилища. **Это план, а не реализованная возможность.** Полнота SQL, производительность и надёжность будут оцениваться только после реализации и испытаний.

SedravaSQL развивается отдельно от [языка Sedrava](https://github.com/VasiliiBabkin/sedrava), чтобы ею могли пользоваться приложения на разных языках.

## Что уже работает?

**Пока ничего из функций СУБД.** Подготовлена начальная документация проекта. Ни установку, ни пример рабочего SQL-запроса сейчас предложить нельзя.

| Направление | Статус |
| --- | --- |
| Цели, архитектура, критерии проверки | Документируются |
| Ядро, CLI и SQL-интерфейс | Не реализованы |
| Предварительная проверка массовых изменений | Запланирована |
| Журнал изменений | Запланирован |
| Проверяемое восстановление | Запланировано |
| Стабильный API и производственный релиз | Отсутствуют |
