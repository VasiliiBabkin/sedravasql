# B16a — типизированные таблицы на нативном журнале

Rust API table::Tables, TableSchema/Column/ColumnType/Cell/Row/TableMutation. Схема неизменяема, 1..16 обязательных столбцов int (i32), bool, text (до 1024 Unicode scalar, без control characters); один text primary key с правилами native key (ASCII letters/digits, -_.). Имена таблиц/столбцов ASCII, case-sensitive. Каталог sedravasql_table_catalog, строки в sedravasql_table.TABLE с SHA схемы. Только выделенный доверенный журнал: raw KV writes в эти пространства запрещены контрактом, не изолированы механизмом безопасности. Нет NULL, ALTER/DROP, FK, JOIN, SQL parser, вторичных индексов. JSON input доверенный, стандартный serde JSON parsing. CAS и идемпотентность наследуются от NativeLog. Scan 1..256 записей, сортировка по primary key, exclusive after, включает tombstones, отдельные CLI-вызовы не общий snapshot. Пакет 1..16 typed put/delete across tables, все проверки до единого commit_batch. Tombstone сохраняет ревизию и предотвращает ABA.

CLI table-create FILE REQUEST_KEY SCHEMA_JSON; table-schema FILE TABLE; table-put FILE REQUEST_KEY TABLE EXPECTED_REVISION ROW_JSON; table-delete FILE REQUEST_KEY TABLE KEY EXPECTED_REVISION; table-get FILE TABLE KEY; table-scan FILE TABLE LIMIT [AFTER]; table-batch FILE REQUEST_KEY CHANGES_JSON.

Schema example: {"name":"Orders","primary_key":"id","columns":[{"name":"id","kind":"text"},{"name":"amount","kind":"int"}]}. Row: {"id":"order-1","amount":100}. Batch: [{"kind":"put","table":"Orders","expected_revision":0,"row":{"id":"order-1","amount":100}}]. CLI write returns underlying NativeCommit. Read returns TableRow with values object or null (tombstone), absent row null. Verify: scripts/verify_native_archive_table.py. VDS: 2 new Rust tests, multi-table CAS rejection, typed rejection, ordered read, replay/reopen, archive exact restore PASS.
