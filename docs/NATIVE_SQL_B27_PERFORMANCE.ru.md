# B27 — оптимизация JSON-декодирования типизированных строк

База: b1520775cb1a7977c8535889b16646a559104b33 (B26). Два независимых эксперимента, в каждом ABBA, 6 баз на вариант по 300 строк, CPU 0 общего VDS 2 vCPU, release build. Проверяются точные результаты каждого запроса относительно SQLite. В конце каждой базы NativeLog verify / SQLite integrity_check. Сторонняя нагрузка заметна; абсолютные времена между сериями не объединяем.

## B27-A: прямой ограниченный кеш (отклонён)

512 слотов, строки до 4096 байт encoded; попадание только по адресу, ревизии, хешу схемы. Корректность при обновлении, удалении, повторе, reopen и corruption прошла. Но кеш не даёт убедительного общего выигрыша: дополнительное копирование и коллизии — возможные причины, а не доказанный профиль. Код кеша исключён из текущего движка.

## B27-B: прямой serde Visitor (принят)

Cell сохраняет прежнее untagged JSON-представление, Serialize неизменён. Вместо общего буфера и проб вариантов Deserialize выбирает непосредственно i32, bool или text. Переполнение i32, дробные значения, null, массивы и объекты отклоняются. Типы, ключи, хеши схемы и границы строк в Tables остаются проверяемыми; журнал, replay, fsync, лимиты и B+Tree не менялись.

## Проверки

66 native-engine tests PASS; strict Clippy PASS. Новый тест сравнивает предыдущий untagged Cell и новый Visitor на 32 фиксированных JSON-строках и 2049 целых числах, дополнительно на serde_json::Value, с round-trip принятых значений. Не утверждаем универсальную совместимость произвольных форматов Serde; используемый формат — JSON.

## Воспроизведение

[Исходные результаты, исходник, Cargo.lock и инструмент RSS](../evidence/benchmark/b27-2026-11-24/). Собрать в отдельном workspace с той же относительной path-зависимостью на native-engine; Cargo.toml.txt и Cargo.lock.txt переименовать в Cargo.toml и Cargo.lock. Release, taskset -c 0, private fixture dirs (umask 077). cc -O2 measure.c -o measure; ./measure /absolute/path/to/benchmark /private/fixture-dir > raw.json 2> rss.txt. Baseline и candidate строить из соответствующего commit/tree, не смешивать библиотеки. Raw JSON содержит все отсортированные samples; summary.json содержит SHA-256, метрики, RSS, порядок и ограничения. Отклонённый cache не находится в активном коде.
