# B15b — проверяемый сжатый архив журнала

SEDRARC1: 8-byte magic, u64 big-endian исходный размер, u64 sequence, SHA-256 исходника, zlib stream (flate2 Rust backend), SHA-256 всего предшествующего контейнера. Исходник ограничен 64 MiB, контейнер 65 MiB. Декомпрессия ограничена объявленным размером+1, требует StreamEnd, точного расхода входа и SHA; после неё проверяются все кадры SEDRLOG1. Требуется приватный каталог и эксклюзивная блокировка источника и нового назначения. Команды archive-create SOURCE DEST SOURCE_SHA256, archive-verify ARCHIVE, archive-restore ARCHIVE DEST ARCHIVE_SHA256. Ожидаемые SHA lowercase. Восстановление только в новый файл, исходник и архив не изменяются; повторная проверка и sync_all файла и каталога. Архив НЕ writable checkpoint, НЕ online compaction, не гарантирует уменьшение размера для всех данных. Существующие форматы и квитанции сохранены. Сбой процесса во время создания может оставить частичный файл и stale lock для ручного рассмотрения. Никакого автоматического удаления исходника.

VDS: 2 новых Rust tests; независимый Python zlib+SHA CLI roundtrip с B16a, исходник 89419 bytes, архив 3107 bytes; точное восстановление, историческая квитанция и tombstone. Проверены повреждённые/обрезанные контейнеры, повторно вычисленная внешняя сумма, чужой SHA, занятый источник и существующее назначение. Не production.
