# B34b — проверяемая обратная миграция в NativeLog

Исследование от B34a c6f7ef8. Команда `sedravasql-native-preview migration-restore IMAGE NEW_LOG` восстанавливает новый канонический SEDRLOG1 из исторических квитанций миграционного COW-образа. Исходный образ и исходный журнал не изменяются.

До создания назначения: полный snapshot образа, сортировка всех квитанций по sequence, восстановление исходных операций из исторических результатов (expected revision = revision-1, put/delete), проверка batch fingerprint и результата штатным prepare/apply, построение канонических frames с цепочкой SHA-256, проверка ограничений NativeLog, полное совпадение manifest и каждого физического record с вновь построенным образом. Требуется совпадение исходного terminal chain hash; неканонический, но читаемый NativeLog с иной сериализацией отклоняется без записи. Формат не является заменой резервного копирования исходных байтов для произвольных старых сериализаций.

Публикация только в приватном каталоге: эксклюзивная блокировка, create_new staging .migration.tmp, fsync, повторная проверка журнала, hard link без перезаписи, fsync каталога, удаление staging и fsync каталога. После аварии между link и unlink два hard links — обычный NativeLog отклоняет такой файл до операторского разбора. Не происходит автоматической очистки stale lock/stage. Не квалифицировано для физического отключения питания или всех файловых систем.

4 целевых теста PASS (включая crash-child): точный round-trip NativeLog с 64 KiB Unicode, SQL sequential transaction и историческими SELECT results; сравнение исходного и восстановленного файла побайтно, сохранение SQL replay и результатов запроса, no overwrite; пустой источник; отказ для синтаксически допустимого неканонического frame с изменённым checksum; два реальных process exit сценария после stage и link с безопасным восстановлением после ручного разбора. Полная регрессия B34a 99/99 PASS. Логи в evidence/benchmark/b34b-reversible-2026-11-25.

Следующий этап — writable COW adapter с упорядоченным адресным пространством и соответствием NativeLog/SQL contract. Основной SQL backend пока NativeLog.
