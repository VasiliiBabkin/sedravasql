# SedravaSQL 0.1 alpha — реальный контракт

**Экспериментальный Linux x86_64 прототип.** Не stable и не production.

## Реализовано

- Rust CLI и библиотека поверх SQLite (rusqlite 0.32.1, bundled SQLite).
- SQLite: WAL, synchronous=FULL, foreign_keys=ON; версия схемы 1
  через PRAGMA user_version. Неизвестная и чужая схема отклоняется.
- Ограниченный API ключ/значение в пространстве `namespace`.
  Значение — UTF-8 до 65536 байт; нет произвольного SQL.
- Предварительный просмотр изменений и CAS по ревизии каждой строки.
  Конкурентный писатель, опередивший план, вызывает CONFLICT.
- Удаление оставляет ревизию (tombstone/NULL) для защиты от ABA.
- Изменение строки, аудит и квитанция запроса записываются в
  одной SQLite-транзакции BEGIN IMMEDIATE. Тот же ключ запроса
  с идентичными параметрами возвращает сохранённую квитанцию;
  другой запрос с занятым ключом отклоняется.
- Аудит хранит отпечатки значений SHA-256, а не старые открытые
  значения. Он не защищён от изменений администратором файла.
- Резервная копия через SQLite Backup API (без перезаписи
  имеющегося файла). Проверяется целостность и схема БД.

## CLI

`init`, `version`, `get`, `list`, `plan-put`, `put`,
`plan-delete`, `delete`, `audit`, `verify`, `backup`.
Вывод — JSON, ошибки — с кодом категории. Параметры изменений
передаются через подготовленные SQL-запросы.

## Проверено

- 4 Rust интеграционных теста;
- 12 параллельных экземпляров CLI: одна успешная запись, 11
  отклонений устаревшей ревизии;
- 4 точки аварийного завершения процесса в debug: после
  изменения строки, после аудита, до COMMIT и после COMMIT.
  После повторного открытия данные, аудит и квитанция согласованы;
- backup включает подтверждённые данные, ещё находящиеся в WAL
  при открытом стороннем соединении SQLite;
- некорректные аргументы, чужая схема, symlink, превышение
  допустимого размера и удаление без подтверждения отклоняются.

Это не power-loss тест. Нет права на заявления exactly-once после
потери диска, отката файла или злонамеренной модификации владельцем.
Нет общего SQL, прав пользователей, резервирования, миграций,
сетевого доступа, кроссплатформенного релизного gate.
