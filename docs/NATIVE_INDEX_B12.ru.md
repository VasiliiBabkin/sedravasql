# Native B12 — постраничное чтение неизменяемого индекса

`VerifiedIndexReader::range_page(namespace,start,end,limit,cursor)` возвращает `rows` и `next`. Границы [start,end), лексикографический порядок, 1..256 записей, включая tombstones. `next` — null на последней странице, иначе объект с index_sha256, namespace, start, end, after (последний возвращённый ключ). Следующая страница начинается строго после этого ключа. Лимит страницы может меняться. Проверяется точное совпадение SHA-256 индекса и области запроса, существование after в диапазоне. Курсор не подписан: он не является авторизацией и доверенный клиент может вручную выбрать позицию. Индекс открывается и полностью проверяется при каждом отдельном запуске CLI; в рамках сессии API повторной полной проверки нет. Одна позиция seek на непустую страницу, проверка SHA каждой строки сохраняется. Формат SEDRIDX1 не меняется.

CLI: `sedravasql-native-preview index-page INDEX NAMESPACE START END LIMIT [CURSOR_JSON]`. Необязательный курсор — JSON-объект из поля next предыдущего ответа, переданный одним аргументом (до 2048 байт).

VDS: 39 native Rust + 21 SQLite Rust, строгий Clippy, B9–B12 CLI PASS. Независимый тест: 41 строка за 9 страниц без пропусков/дубликатов, tombstone, меняющийся лимит, пустой диапазон, изменённый курсор и новый снимок. Rust-тест: 64 записи за 10 страниц, 10 seek. Не живой индекс, не SQL-планировщик, не гарантия безопасности от недоверенного владельца файла.
