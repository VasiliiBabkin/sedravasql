# Security policy / Безопасность

## Supported versions

**None.** SedravaSQL has no executable release and is not intended for production use. No security maintenance or response-time commitment is currently provided.

## Reporting

- For general, non-sensitive design and documentation issues, use GitHub Issues.
- **Do not disclose a vulnerability, exploit details, secrets, or private data in a public issue.**
- No private security reporting channel has **yet been verified or documented** for this project. Check the repository's Security tab for an up-to-date private reporting option, if enabled; otherwise contact the maintainer privately through an independently verified channel before sharing sensitive details.
- Do not send credentials, private database copies, or personal records even in a private report unless explicitly necessary and appropriately protected.

## Guarantees

No encryption, authentication, isolation, tamper resistance, vulnerability response SLA, secure-by-default configuration, or production security guarantee is claimed for SedravaSQL at this stage.

## По-русски

Рабочих релизов и поддерживаемых версий ещё нет. Не публикуйте сведения об уязвимостях, ключи доступа и личные данные в открытых Issues. Наличие приватного канала уведомлений пока не подтверждено.
